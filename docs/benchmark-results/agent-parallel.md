# 实验③：多 Agent 串行 vs 并行耗时

## 运行环境
- 运行时间: 2026-08-16 16:36:55
- OS: Windows 10 / amd64
- JDK: 21.0.6
- CPU 核数(可用): 12
- 模式: Mock（模拟 Agent 固定 800ms/个，验证调度机制）
- Agent 数: 4（编辑/人物/风格/读者），轮数: 2

| 轮次 | 串行总耗时(ms) | 并行总耗时(ms) | 加速比 |
|---|---|---|---|
| 1 | 3250 | 805 | 4.0x |
| 2 | 3228 | 814 | 4.0x |
| **平均** | **3239.0** | **809.5** | **4.0x** |

> 结论：并行调度平均耗时 **809.5ms**，串行 **3239.0ms**，加速比 **4.0x**（4 Agent 上限 4x，实际接近线性扩展）。
