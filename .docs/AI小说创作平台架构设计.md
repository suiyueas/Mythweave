# AI智能小说创作平台 - 功能架构设计（智能增强版）

## 设计方案概述

### 技术基底

- 后端：Spring Boot 3.5 + Java 21 + MyBatis Plus + MySQL
- 前端：Vue 3 + Vite 7 + Tailwind CSS 4 + Pinia + Vue Router（自研编辑器组件）
- AI主模型：DeepSeek v4 Pro API（流式SSE + 非流式双模式）
- AI Embedding：千问 text-embedding-v3（阿里云百炼，1024维中文向量）
- 向量检索引擎：Elasticsearch 8.x（dense_vector + kNN + BM25混合检索）
- 新增依赖：自研Agent编排器(Orchestrator)、Spring Data Elasticsearch（ES客户端）、Redis（缓存/任务队列）、WebSocket（实时状态推送）

### 平台定位

面向作者个人的全能型AI写作工作台，核心目标是**"让AI成为作者的副脑"**——不止是被动响应指令的工具，更是拥有全书记忆、能主动发现问题、多角色协同思考的创作伙伴。覆盖从灵感→大纲→写作→润色→导出全流程。

### 四维智能增强支柱

- **记忆**：RAG + ES向量检索，AI记住全书上下文，写第50章时知道第1章发生了什么
- **主动**：后台智能哨兵自动巡查伏笔遗漏、逻辑矛盾、节奏崩塌，主动推送告警
- **协作**：多Agent各司其职（编辑/人物/风格/读者），像一个微型写作工坊
- **学习**：提取作者风格指纹，让AI续写越来越贴合个人文风

## 功能模块全景（17大模块）

### 一、作品项目管理

- 多作品并行管理（创建/编辑/删除/归档）
- 作品元信息（封面、简介、标签、类型、目标字数）
- 写作目标设定与进度追踪
- 作品模板（玄幻/都市/科幻/悬疑等类型模板）
- 回收站机制

### 二、故事结构（智能大纲）

- 树形/思维导图式大纲编辑器（前端侧边栏显示为「故事结构」）
- AI一键生成大纲（输入一句话梗概，AI展开完整大纲）
- 经典叙事结构模板（三幕式/英雄之旅/二十四章经/救猫咪节拍表）
- 大纲拖拽排序、层级调整
- 大纲节点关联正文（大纲与正文双向联动）
- 大纲版本快照与对比
- AI结构诊断：分析大纲与所选叙事结构模板的匹配度，输出结构评分与改进建议
- 章节密度预测：基于大纲节点自动估算每个节点的合理字数范围
- 大纲-正文同步度检查：检测正文是否偏离大纲，偏离超阈值自动提醒

### 三、人物工坊

- 人物档案卡（基本信息、外貌、性格、背景故事、成长弧光）
- AI批量生成人物（基于世界观自动生成配角群像）
- 人物关系图谱可视化（力导向图，支持拖拽编辑）
- 人物出场频率热力图
- 人物对话风格预设（AI记住每个角色的说话方式）
- 人物一致性检测（AI检查人物行为是否符合设定）
- 人物弧光进度追踪：设定弧光目标（如"从懦弱到勇敢"），AI定时评估当前进度
- 人物状态快照：每章记录人物当前状态（情绪/位置/关系/目标），形成人物状态时间轴
- 跨角色关系动态分析：追踪关系变化轨迹（陌生人→朋友→背叛→和解），可视化关系演变

### 四、世界观构筑器

- 分层世界观设定（地理→历史→文化→规则体系→种族/势力）
- AI辅助世界观生成与补全
- 术语/专有名词词典（自动检测文中术语一致性）
- 场景/地点管理（地图标记、场景描述模板）
- 时间线/编年史管理

### 五、智能写作编辑器（核心）

- 双栏编辑器（左大纲/右写作区）
- Markdown + 富文本双模式
- AI流式续写（光标处触发，实时流式输出，可随时中断/回退）
- 上下文感知续写：由Context Engine自动装配全书相关前文，续写不再"失忆"
- AI扩写（选中段落→AI扩展细节）
- AI缩写（选中段落→AI精简提炼）
- AI改写/润色（多风格可选：更生动/更简洁/更文艺/更网文化，支持风格引擎约束）
- AI描写辅助（场景描写/人物描写/心理描写/动作描写一键生成）
- AI对话生成（指定角色A对角色B说话，人物Agent守护对话风格一致性）
- 智能联想（写作中自动提示后续情节走向）
- 智能分镜建议：AI分析当前位置的叙事节奏，建议"此处应加速""此处可放缓描写"
- 写作意图识别：识别场景类型（战斗/对话/独白/转折），自动切换AI辅助模式
- 实时AI跟随提示：不打断写作流，侧边栏静默提示伏笔关联、风格偏差等
- 敏感词/违规内容实时检测
- 语法/错别字/病句检测

### 六、情节引擎

- 情节线索管理（主线+支线，可视化追踪）
- 伏笔系统（埋设伏笔→标记→揭示提醒，防遗忘）
- 冲突设计器（人物冲突/利益冲突/价值观冲突分析）
- 情节节奏分析（紧张-舒缓曲线图）
- 多线叙事交叉点管理
- AI情节医生（检测逻辑漏洞、时间线矛盾）
- 情节知识图谱：人物-事件-地点-伏笔多维关系图（MySQL图关系表实现）
- 自动情节元素提取：从已写章节中AI自动识别人物行动、关键事件、转折点，填充知识图谱
- 情节完整度评分：AI评估主线断点、支线收束需求
- "蝴蝶效应"推演：修改某情节节点，AI推演对后续情节的连锁影响

### 七、章节管理

- 章节列表（拖拽排序、批量移动）
- 分卷管理（卷→章→节三级结构）
- 章节版本管理（自动保存历史版本，支持版本对比/回滚）
- 章节状态标记（草稿/完成/需修改/已锁定）
- 章节合并/拆分
- 章节间前后文一致性提示

### 八、AI写作对话助手（多Agent对话）

- 侧边栏AI对话（随时与AI讨论剧情，支持指定Agent：编辑/人物/风格/读者）
- AI流式对话（SSE实时输出，前端EventSource接收）
- AI章节生成（SSE流式输出完整章节内容，含上下文自动装配）
- AI章节标题自动生成
- 角色模拟器（AI扮演书中角色与你对话，找灵感，人物Agent确保角色还原度）
- "如果…会怎样"推演（分支剧情探索，蝴蝶效应分析）
- 读者视角模拟（AI以不同类型读者身份反馈读后感）
- 写作瓶颈突破建议
- Agent对话会话管理：按Agent类型归档，支持上下文延续

### 九、素材与灵感库

- 灵感速记（便签式快速记录）
- 素材收集板（图片/网页链接/文本片段）
- 参考资料库（研究资料分类管理）
- 标签/分类体系
- 灵感随机漫步（AI基于现有素材生成新灵感）

### 十、写作分析

- 仪表盘（今日字数/本周字数/总字数/写作时长）
- 写作速度趋势图
- 章节字数分布柱状图
- 人物出场统计
- 情感曲线分析（AI分析章节情绪走向）
- 每日写作日历热力图（类似GitHub贡献图）
- 叙事深度分析仪表盘：情绪曲线热力图、对话占比趋势、描写类型分布
- 章节质量评分：综合AI评估（节奏/逻辑/人物/文风四维），ES聚合时序数据
- 写作生产力洞察：分析最佳写作时段、写作速度与质量关系
- 全书健康度一览：伏笔回收率、人物出场均衡度、节奏变化频率

### 十一、批量操作与导出

- 多格式导出（TXT / Markdown / PDF / Word / HTML）
- 自定义排版模板

- 导出预览

### 十二、AI策略配置

- AI模型参数调节（温度/Top-P/Max Tokens）
- 写作风格预设管理（创建/保存/切换风格预设）
- 自定义Prompt模板（高级用户自定义AI行为）
- Token用量统计与成本估算
- AI响应缓存（减少重复调用成本）

### 十三、个人设置与偏好

- [ ] 编辑器主题/字体/字号自定义
- [ ] 写作模式切换（专注模式/大纲模式/双栏模式）
- [ ] 快捷键自定义
- [ ] 自动保存间隔设置
- [ ] 云同步开关

### 十四、全知上下文引擎（Context Engine）

- 全书向量索引：章节/人物/设定/大纲/术语均通过千问Embedding向量化存入ES
- 分层索引策略：人物/设定/术语采用摘要级索引，章节采用段落级滑动窗口索引
- ES混合检索：语义向量相似度（cosine）+ BM25关键词匹配，加权融合排序
- 上下文自动装配：写作时根据光标位置，自动检索Top-K相关前文内容，组装为结构化System Prompt注入AI调用
- 语义搜索：支持跨全书自然语言搜索，如"主角第一次遇见反派的场景"
- 索引生命周期：章节保存后自动增量更新ES索引，支持手动全量重建

### 十五、多Agent协同工作室（Multi-Agent Studio）

- 编辑Agent：分析章节节奏、检测逻辑矛盾、评估伏笔回收率
- 人物Agent：守护人物行为与档案设定一致性、对话风格匹配度
- 风格Agent：比照作者风格指纹，对续写/润色输出风格约束建议
- 读者Agent：模拟不同类型读者视角，给出读后感受反馈
- 编曲器（Orchestrator）：管理Agent调度、上下文分发、结果聚合
- 三种调用模式：写作中同步调用单Agent / 章节完成后异步批处理多Agent并行分析 / 侧边栏对话模式

### 十六、主动智能哨兵（Proactive Sentinel）

- 事件驱动巡查：章节标记"完成"自动触发巡查；每日凌晨全书深度巡查
- 伏笔巡查：检测已埋未收回的伏笔，验证伏笔回收时是否呼应前文
- 逻辑巡查：时间线矛盾检测、人物位置冲突检测、设定冲突检测
- 人物巡查：人物长期未出场提醒、人物弧光进度停滞告警
- 节奏巡查：连续章节节奏单一检测、情绪曲线异常告警
- 性能考量：全书深度巡查采用分片异步执行策略——将全书按卷/大章节切分为多个巡查分片，通过Redis任务队列分发到独立Worker逐片处理，避免阻塞主业务线程；仅巡查自上次检查后标记变更的章节（增量检测），大幅降低长篇作品（百万字级）的巡查耗时
- 智能提醒：站内通知铃铛 + 按严重程度排列的问题面板 + 每条告警附带AI修复建议

### 十七、作者风格引擎（Style Engine）

- 风格指纹提取：取作者已确认/锁定的章节作为"黄金样本"，多维提取文风特征
- 五维风格特征：句式特征（句长/节奏）、词汇特征（高频词/成语率）、修辞特征（比喻/拟人密度）、叙事特征（视角切换/独白比例）、标点习惯
- 风格向量编码：特征量化为结构化"风格配置文件"
- 续写风格注入：AI续写/润色时将风格配置注入System Prompt，约束输出匹配个人文风
- 风格进化追踪：随写作量增长持续更新风格指纹，追踪文风演变
- 风格相似度评分：AI生成内容与黄金样本比对，低于阈值自动标记提醒复核

## 关键技术决策

1. **流式输出**：使用Spring SSE（Server-Sent Events），前端EventSource接收，编辑器实时渲染
2. **版本管理**：章节采用增量存储+版本链，支持diff对比
3. **编辑器**：前端自研Vue组件编辑器，支持Markdown + 富文本双模式，内嵌AI流式续写交互
4. **AI调用**：封装DeepSeekClient统一管理Prompt、重试、Token计数、流式/非流式切换
5. **缓存策略**：Redis缓存热点数据（大纲树、人物列表），减少DB查询
6. **RAG上下文引擎**：千问text-embedding-v3做中文向量化（1024维），ES 8.x存储向量索引，dense_vector + kNN + BM25混合检索，写作时自动装配全书相关上下文注入AI调用
7. **多Agent协作**：自研Orchestrator编排4个专精Agent（编辑/人物/风格/读者），支持同步单Agent、异步批处理并行（CompletableFuture线程池）、对话三种模式。**复杂度说明**：多Agent并行时存在上下文传递开销（每个Agent需独立的System Prompt + 关联上下文装配，单次批处理Token消耗约为单Agent的3-4倍）、结果冲突消解（不同Agent可能给出矛盾建议，需Orchestrator做加权仲裁）。**降级方案**：当Token预算紧张或响应延迟超标时，自动降级为"串行优先模式"——优先运行编辑Agent做结构分析，仅当检测到明确问题域时才唤起对应专精Agent（人物/风格/读者），避免全量并行造成的成本浪费和响应延迟
8. **主动智能哨兵**：Spring @Scheduled + Redis异步任务队列，章节完成事件驱动 + 每日凌晨全书深度巡查，伏笔/逻辑/人物/节奏四维巡检
9. **风格引擎**：五维风格特征提取（句式/词汇/修辞/叙事/标点），结构化风格配置文件，AI续写时注入System Prompt约束文风匹配
10. **ES混合检索**：语义向量相似度 + BM25关键词匹配加权融合，兼顾"意思相近"和"关键词精确命中"
11. **存储分层**：MySQL主库管业务CRUD + ES管向量检索/全文搜索/日志聚合 + Redis管缓存/队列，各司其职无需替换数据库
